# Orchit text animation preset

Version 1 defines preset identity, timing, and ordered property keyframes. Keyframe times are microseconds relative to the animated overlay; easing is a supported easing name. Optional bundled font assets use a local path and an SPDX `license`. Unknown fields and unsupported versions are rejected.

Schema: `schemas/text-animation.schema.json`. Sample: `samples/text-animation.json`.
